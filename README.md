# 下载整理助手 · Download Organizer

一个轻量的 macOS 原生下载文件整理工具，使用 SwiftUI 编写。先预览、勾选，再按文件类型整理，支持撤销。

## 功能

- 默认读取当前用户的“下载”文件夹，也可以选择其他文件夹。
- 按图片、文档、视频、音频、压缩包、安装包、代码与配置、其他文件分类。
- 显示待整理文件、所选数量、大小和目标分类目录。
- 重名时自动添加编号，保留已有文件。
- 跳过子文件夹、隐藏文件、符号链接、Finder 替身和未完成下载。
- 跳过最近 60 秒修改过的文件；稍后点击刷新即可重新预览。
- 保存本地操作记录，关闭程序后仍可撤销。
- 整理前核对文件状态；撤销时跳过已修改文件和被占用的原路径。
- 不联网，不上传文件，不递归整理子文件夹。

## 系统要求

- macOS 14 或更新版本。
- 构建需要 Apple Command Line Tools 或 Xcode。
- 无第三方依赖，构建脚本为当前 Mac 的架构生成应用。

## 构建和运行

```sh
git clone https://github.com/Vles0123/download-organizer.git
cd download-organizer
bash scripts/build.sh
open "dist/下载整理助手.app"
```

缺少编译工具时，先运行 `xcode-select --install` 并完成系统安装提示。

构建脚本会编译、进行本地临时签名并运行自检。应用输出到 `dist/下载整理助手.app`，可以将其拖到“应用程序”目录。

## 使用

1. 打开应用，查看文件预览。
2. 按需筛选类型，勾选要整理的文件。
3. 点击“整理所选”，将文件移入当前文件夹内的分类目录。
4. 需要恢复时点击“撤销最近一次”。完成后可以继续撤销更早的批次。

“全选”和“取消选择”只影响当前筛选下显示的文件，整理按钮显示所有类型合计的选择数量。重名编号在实际整理时确定。

## 撤销和限制

本地撤销记录位于：

```text
~/Library/Application Support/DownloadOrganizer/history/
```

每次移动前先保存意图记录，以便恢复意外中断的批次。请保留此目录。如果整理后的文件已修改、移动或删除，或者原位置被新文件占用，撤销会跳过该项并给出详情。有冲突的最新批次会保留，解决冲突后可重试。

文件状态通过设备号、inode、大小和修改时间核对，未计算文件内容哈希。分类依据为扩展名；例如 `.ts` 归入代码与配置，不能区分 TypeScript 和 MPEG-TS 视频。60 秒保护是启发式检查，无法识别所有下载器的工作状态。

在同步盘中整理文件时，对应同步软件可能同步文件移动。此工具不提供文件备份，建议首次使用时在测试文件夹中确认分类是否符合需要。

## 自检

构建自动运行自检，也可单独执行：

```sh
"dist/下载整理助手.app/Contents/MacOS/DownloadOrganizer" --self-test
```

自检只使用随机临时目录，覆盖筛选规则、重名保留、整理与撤销、原位置冲突、文件修改、失效预览、目标目录链接以及中断后的恢复，不操作真实下载目录。
